# Conductor 0.4.0

Conductor provides durable task tracking for native Codex agents. A lead agent works directly on one coherent task and coordinates workers when there are distinct workstreams.

## Install on Windows

Download `ConductorSetup.exe` below and run it as the Windows user who uses Codex. Choose an app folder, a separate task-data folder, and Codex desktop, VS Code, or both. The local installer has completed in a user-led setup for both clients.

The installer supports resuming in an existing Conductor-owned app folder, merges its required Codex settings into the current configuration, and avoids a recursive Windows permission change.

## Other setups

The repository also contains a local macOS installer and Linux VM deployment options, including shared MySQL. See the [README](https://github.com/gonzoinc/Conductor/blob/v0.4.0/README.md) for the setup that fits your use.

This release is built from the tagged public source. The release workflow checks the public tree and installer payload, runs Windows setup tests and the packaged-app self-test, and publishes a SHA-256 checksum beside the installer.
