# Conductor 0.4.0b1 preview

This preview provides a local Windows setup app for a single-user Conductor ledger and an optional Linux service installer for shared deployments. Conductor tracks work across native Codex agents; Codex handles agent creation and execution.

## Windows local setup

Download `ConductorSetup.exe` and run it as the Windows user who uses Codex. Choose an app folder, a separate task-data folder, and Codex desktop, VS Code, or both. Separate test profiles are available when you want to try the integration before changing your normal Codex settings.

This build can resume in an existing Conductor-owned app folder. It merges required Codex configuration into the current file and no longer performs a recursive permission change during setup.

## Validation and scope

The Windows setup was completed in a local user walkthrough. The release build runs the public-source guard, installer payload check, Windows setup tests, and packaged-app self-test before publishing. Native worker behavior still depends on the Codex desktop or VS Code version in use; see the [acceptance notes](https://github.com/gonzoinc/Conductor/blob/v0.4.0b1/docs/acceptance.md) for the checks that remain.

The downloadable executable is the Windows local setup app. Linux host installation and MySQL configuration are provided as source in this repository; follow [host setup](https://github.com/gonzoinc/Conductor/blob/v0.4.0b1/docs/host-install.md) on the target VM.
